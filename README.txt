GLOBAL GWALA WEBSITE - STANDALONE COPY
======================================

How to open
1. Unzip this folder. Keep index.html and the "img" folder together.
2. Double-click index.html (Chrome or Edge recommended).
3. Admin panel: open the "Admin" link in the menu (or add #admin to the address).

What works
- Everything: all modules, filters, admin panel (all tabs), bulk upload/download,
  products, cart, checkout, orders, sign up, members, themes, logo, reports.
- It starts with your live data as of 11 Oct 2026 (modules, listings, products, settings).

Important
- In this copy, data is saved ONLY in this browser on this computer (browser storage).
  It is not shared with other people or other devices.
- Admin > Overview > "Download full backup" saves all data as a .json file.
  "Restore backup" loads it on another computer/browser.
- Clearing browser data deletes it. Download a backup regularly.
- Whoever opens this file on their own computer is the owner of that copy.
- Internet is needed for fonts, Excel upload/download and the UPI QR code.

To run it as a public website (globalgwala.in) where many users share one database,
the storage layer must be connected to an online database (e.g. Firebase or Supabase).
